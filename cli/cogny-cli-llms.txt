# Cogny CLI — machine-readable tool map

> Every Cogny MCP server is callable from your shell via @cogny/cli, which wraps the
> cogny-mcp-proxy. No native MCP wiring and no agent restart required. The first 15
> calls per month are free. Human-readable index: https://cogny.com/cli

## Quickstart

```bash
# 1. sign up + issue an API key (uses your git config user.email)
npx @cogny/cli init --agent claude-code

# 2. list every tool + input schema for your connected servers
cogny tools list --json

# 3. call any tool over JSON-RPC + Bearer auth
cogny tools call <tool> --input '<json>'
```

Tool names are namespaced as `mcp__<toolPrefix>__<tool>`. Connect a server, then run
`cogny tools list` to see its exact tools and input schemas.
